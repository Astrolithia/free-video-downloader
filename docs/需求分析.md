# FreeVidGrab 需求分析文档

## 1. 项目概述

### 1.1 项目背景

随着短视频和长视频平台的蓬勃发展，用户在不同平台上观看并收藏了大量优质视频内容。然而，由于网络环境限制、平台策略变化或离线观看需求，用户经常需要将视频保存到本地设备。市面上的视频下载工具大多存在广告泛滥、功能受限或安全风险等问题。

FreeVidGrab 旨在提供一个**开源、自部署、无广告**的万能视频下载方案，让用户通过简洁的 Web 界面，一键解析并下载来自 1000+ 平台的视频内容。

### 1.2 项目定位

- **产品名称**：FreeVidGrab — 万能视频下载器
- **目标用户**：需要下载网络视频进行个人学习、研究的用户
- **核心价值**：简单易用、平台覆盖广、支持清晰度选择、实时进度反馈
- **部署形态**：自托管 Web 服务，用户在本地或服务器上部署后通过浏览器访问

## 2. 功能需求

### 2.1 视频链接解析

| 项目 | 说明 |
| --- | --- |
| 描述 | 用户粘贴视频页面链接，系统自动提取视频元信息 |
| 输入 | 任意包含视频 URL 的文本（支持从分享文案中自动提取链接） |
| 输出 | 视频标题、缩略图、时长、上传者、可选清晰度列表 |
| 平台覆盖 | 基于 yt-dlp 支持 YouTube、B 站、Twitter/X、Instagram 等 1000+ 平台 |
| 特殊处理 | 抖音/TikTok 链接通过独立模块解析（无需 Cookie，使用移动端分享页） |
| 容错 | 解析失败自动重试（最多 2 次），返回友好的中文错误提示 |

**用户交互流程**：

1. 用户在输入框粘贴视频链接
2. 系统支持粘贴后自动触发解析（300ms 延迟防抖），也可手动点击"解析视频"按钮
3. 解析中显示加载动画
4. 解析成功后展示视频信息卡片和清晰度选项

### 2.2 清晰度选择与下载

| 项目 | 说明 |
| --- | --- |
| 描述 | 用户从解析结果中选择目标清晰度，发起下载 |
| 清晰度展示 | 按分辨率从高到低排列（如 1080p、720p、480p），去重显示 |
| 音视频合并 | 当视频流不含音频时，自动选择最佳音频流进行合并（通过 ffmpeg） |
| 格式输出 | 统一合并为 MP4 格式 |
| 默认选择 | 自动选中最高清晰度 |

### 2.3 实时下载进度

| 项目 | 说明 |
| --- | --- |
| 描述 | 下载过程中实时展示进度百分比、下载速度和预计剩余时间 |
| 技术方案 | 基于 Server-Sent Events（SSE）的服务端推送 |
| 状态流转 | `pending` → `downloading` → `merging` → `done` / `error` |
| 心跳机制 | 每 30 秒发送心跳包，防止连接超时断开 |
| 异常处理 | 连接中断时前端提示"连接中断，请重试" |

### 2.4 文件交付

| 项目 | 说明 |
| --- | --- |
| 描述 | 下载完成后用户可点击"保存文件"将视频保存到本地 |
| 文件命名 | 使用视频标题作为文件名（自动清理非法字符） |
| 传输方式 | 通过 HTTP 文件响应流式传输 |

### 2.5 缩略图代理

| 项目 | 说明 |
| --- | --- |
| 描述 | 视频缩略图通过后端代理加载，规避浏览器跨域和 Referer 限制 |
| 缓存策略 | 响应头设置 `Cache-Control: public, max-age=86400`（24 小时缓存） |

### 2.6 抖音视频专项支持

| 项目 | 说明 |
| --- | --- |
| 描述 | 针对抖音/TikTok 提供独立的无 Cookie 解析和下载通道 |
| 实现方式 | 通过移动端分享页 `iesdouyin.com` 提取 `window._ROUTER_DATA` 中的视频数据 |
| 支持链接类型 | 短链（v.douyin.com）、分享链接、标准视频链接 |
| 下载方式 | httpx 流式下载，不依赖 yt-dlp |

### 2.7 文件自动清理

| 项目 | 说明 |
| --- | --- |
| 描述 | 定期清理服务器上的过期下载文件，避免磁盘占满 |
| 清理周期 | 每 10 分钟执行一次 |
| 过期阈值 | 文件创建超过 10 分钟即视为过期 |
| 清理范围 | `downloads/` 目录下的所有过期文件及对应的内存任务记录 |

### 2.8 移动端适配

| 项目 | 说明 |
| --- | --- |
| 描述 | 响应式布局，移动端浏览器可正常使用全部功能 |
| 实现方式 | Tailwind CSS 响应式工具类 |

## 3. 非功能需求

### 3.1 性能

- 视频解析响应时间应在 **10 秒以内**（取决于源站响应速度）
- 支持多用户并发解析和下载（基于异步 I/O 和线程池）
- SSE 进度推送延迟不超过 **1 秒**

### 3.2 可靠性

- 解析失败自动重试（最多 2 次，间隔 1 秒）
- 下载异常时向前端推送明确的错误信息
- 后台清理任务随应用生命周期自动启停，不阻塞主服务

### 3.3 安全性

- 后端对用户输入的 URL 进行正则提取和校验，过滤无效内容
- CORS 配置支持跨域访问（当前为开放策略，生产环境需收紧）
- 缩略图代理仅透传图片类型的响应，不执行任意远端请求的内容

### 3.4 兼容性

- **浏览器**：支持 Chrome、Firefox、Safari、Edge 等主流现代浏览器
- **操作系统**：后端支持 macOS、Linux（需安装 Python 3.10+ 和 ffmpeg）
- **视频平台**：依赖 yt-dlp 持续更新以保持对各平台的兼容

### 3.5 可维护性

- 代码模块化清晰：API 层、服务层、前端分离
- 抖音模块独立于主服务，便于单独维护和扩展
- 依赖版本在 `requirements.txt` 中锁定

## 4. 用户场景

### 场景一：下载 YouTube 视频用于学习

> 用户在 YouTube 上看到一个编程教程，希望保存到本地离线观看。打开 FreeVidGrab，粘贴视频链接，系统解析出视频信息和多个清晰度选项。用户选择 1080p，点击下载，实时查看进度条，下载完成后点击"保存文件"存到本地。

### 场景二：保存抖音短视频

> 用户在抖音 App 中点击分享，复制链接。在 FreeVidGrab 中粘贴包含分享文案的文本，系统自动提取链接并解析。由于是抖音视频，系统走专用通道解析，无需 Cookie 即可获取视频。用户点击下载，视频以 MP4 格式保存到本地。

### 场景三：手机端快速下载

> 用户在手机浏览器中打开 FreeVidGrab，粘贴 B 站视频链接。响应式界面自动适配手机屏幕，解析后选择 720p 格式下载，进度条实时更新，完成后直接保存到手机相册。

---

## 5. 约束与限制

- 本工具**仅供个人学习和研究使用**，用户需尊重视频内容版权
- 视频平台可能随时更改其页面结构或接口，导致解析失败，需及时更新 yt-dlp 或抖音解析模块
- 下载文件在服务端仅保留 10 分钟，超时自动删除
- 当前不支持播放列表批量下载（`noplaylist: True`）
- 不支持需要登录才能访问的私密/会员视频
